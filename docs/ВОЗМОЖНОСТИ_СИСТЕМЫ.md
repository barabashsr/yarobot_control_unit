# Возможности системы управления YaRobot

## Обзор проекта

YaRobot Control Unit — это комплексная встраиваемая система управления для одновременного контроля до 8 независимых осей двигателей различных типов через унифицированный USB-интерфейс. Система обеспечивает высокую производительность, надежность и безопасность для робототехнических применений.

---

## РЕАЛИЗОВАННЫЕ ВОЗМОЖНОСТИ (~70% готовности)

### 1. Многоосевое управление двигателями

**Поддержка 8 независимых осей:**
- **X, Y, Z, A, B**: 5 серво-осей с интерфейсом STEP/DIR и генерацией импульсов через RMT
- **C, D**: 2 шаговые оси с генерацией импульсов MCPWM/LEDC и аппаратным подсчетом позиции
- **E**: 1 дискретный привод с расчетом позиции по времени

**Команды управления движением:**
- `MOVE X 100` — абсолютное позиционирование
- `MOVR X -50.5` — относительное перемещение
- `VEL X 10` — непрерывное движение с заданной скоростью (режим jog)
- `STOP X` — остановка движения с замедлением
- `EN X 1/0` — включение/выключение отдельных осей

**Технические характеристики:**
- Генерация импульсов: до 500 кГц аппаратная возможность, 200 кГц стандартное ограничение на ось
- Задержка команда-движение: <10 мс
- Обновление движения в реальном времени: 1000 Гц через FreeRTOS
- Плавные трапецеидальные профили движения (разгон-движение-торможение)
- Изменение траектории во время движения без остановки

**Отслеживание позиции:**
- Позиция в реальном времени для всех осей
- Энкодер через RMT callback для серво-осей (без нагрузки на DMA)
- Аппаратное обнаружение переполнения PCNT для шаговых/дискретных осей
- Точность позиционирования при смене направления

---

### 2. Системы безопасности

**Аварийная остановка (E-Stop):**
- Аппаратная кнопка E-Stop с откликом <1 мс
- Автоматическое включение тормозов при аварийной остановке
- Все двигатели отключаются и блокируются в текущем положении
- Команда `RST` для восстановления после снятия E-Stop

**Мониторинг концевых выключателей:**
- 14 концевых выключателей (2 на ось) с мониторингом в реальном времени
- Настраиваемое поведение для каждого выключателя: NONE, HARD_STOP, RESTRICT, EVENT_ONLY
- Автоматическая остановка движения при активации концевика
- Предотвращение выхода за пределы хода
- Поддержка антидребезга для шумных выключателей
- Команда `LIM` для запроса состояния концевиков

**Система управления тормозами:**
- **Настраиваемые стратегии для каждой оси:**
  - BRAKE_ON_DISABLE: включается при отключении оси (типично для вертикальных осей)
  - BRAKE_ON_ESTOP: включается только при аварийной остановке
  - BRAKE_ON_IDLE: автовключение после 30-секундного таймаута простоя
  - BRAKE_MANUAL: ручное управление через команду `BRAKE X 1/0`
- Отказобезопасная конструкция: при потере питания все тормоза включаются автоматически
- Контроль времени: 50 мс на включение, 30 мс на отключение
- Команда `BRAKE X 1/0` для ручного управления тормозами

**Обнаружение и восстановление потери позиции:**
- Обнаруживает неожиданные изменения позиции
- Отслеживает события потери питания
- Команда `POSOK X` для подтверждения и восстановления после потери позиции

### 3. Интерфейс связи и командный протокол

**USB Serial интерфейс:**
- CDC (Communications Device Class) через USB-C
- 115200 бод по умолчанию
- Человекочитаемые текстовые команды
- Работает с любым терминальным приложением

**Командный протокол:**
Все команды вводятся без учета регистра в формате: `КОМАНДА [ОСЬ] [ПАРАМЕТРЫ]`

**Реализованные команды:**

| Категория | Команды |
|-----------|---------|
| **Движение** | MOVE, MOVR, VEL, STOP |
| **Управление** | EN (включение), BRAKE, ZERO (сброс позиции), HOME |
| **Запрос** | POS (позиция), STAT (статус), INFO, LIM (концевики), INPOS, WIDTH |
| **Ввод/вывод** | DIN (цифровой вход), DOUT (цифровой выход) |
| **Управление ошибками** | ERRCNT (счетчик ошибок), CLRERR (очистить ошибку), CLR (сброс аварии) |
| **Статус** | DIAG (диагностика) |

**Протокол ответов:**
- Успех: `OK [данные]`
- Ошибка: `ERROR E### ТЕКСТ_СООБЩЕНИЯ`
- События: `EVENT ТИП ДАННЫЕ` (асинхронные уведомления)
- YAML: `YAML: [данные конфигурации]`

**Примеры команд:**
```
MOVE X 100.5          → Переместить ось X в позицию 100.5
MOVR Y -50            → Переместить ось Y на 50 единиц назад
VEL Z 25 1.5          → Непрерывное движение оси Z со скоростью 25 ед/сек и ускорением 1.5
STOP A                → Остановить ось A
EN X 1                → Включить ось X
EN X 0                → Отключить ось X (включает тормоз, если настроено)
POS                   → Запросить позиции всех осей
STAT X                → Запросить статус оси X (состояние, позиция, ошибки)
BRAKE Z 1             → Включить тормоз оси Z (если стратегия BRAKE_MANUAL)
```

### 4. Управление концевиками и вводом/выводом

**Универсальный ввод/вывод:**
- **Цифровые входы:** 4 входа через расширители MCP23017 по шине I2C
- **Цифровые выходы:** 8 выходов через сдвиговые регистры
- `DIN <пин>` — чтение цифрового входа
- `DOUT <пин> <0|1>` — запись цифрового выхода

**Обработка обратной связи от серво:**
- Команда `INPOS X` запрашивает сигнал "в позиции" от серводрайвера
- Мониторинг ошибок позиционирования серво в реальном времени
- Обнаруживает, когда серво не может удержать позицию

**Плавающий переключатель оси C (ширина захвата):**
- Автоматическое измерение ширины с использованием плавающего переключателя оси C
- Команда `WIDTH` возвращает последнее измеренное значение ширины объекта
- Команда `GETWIDTH` запускает новое измерение
- Полезно для применений с захватом/манипулятором

### 5. Отслеживание ошибок и восстановление

**Комплексное отслеживание ошибок:**
- Подсчет ошибок по категориям: I2C, TIMEOUT, LIMIT, ESTOP, POSITION_LOSS
- Отслеживание состояния ошибок для каждой оси
- Предотвращение небезопасных операций при ошибочном состоянии оси

**Команды управления ошибками:**
- `ERRCNT` — отобразить все счетчики ошибок
- `ERRCNT X` — отобразить счетчики ошибок для оси X
- `ERRCNT CLR` — сбросить все счетчики ошибок
- `CLRERR X` — очистить состояние ошибки для оси X
- `CLRERR` — очистить ошибки всех осей

**Формат ответа об ошибках:**
```
ERRCNT           → OK I2C:3 TIMEOUT:1 LIMIT:5 ESTOP:2 POSLOS:0
ERRCNT X         → OK X LIMIT:2 POSLOS:0 TIMEOUT:1
ERROR E032       → Формат кода ошибки с конкретными номерами
```

**Блокировка движения:**
- Команды движения (`MOVE`, `MOVR`, `VEL`) блокируются при состоянии ERROR оси
- Ошибка должна быть очищена через `CLRERR` или ось повторно включена через `EN ось 1`

### 6. Управление аварийными сигналами драйверов

**Мониторинг ALARM_INPUT:**
- Отслеживает аварийные сигналы от внешних драйверов двигателей (оси X-D)
- Обнаружение неисправностей драйвера в реальном времени
- Предотвращение движения при наличии неисправности драйвера

**Сброс аварии:**
- Команда `CLR X` пытается сбросить аварию драйвера через выход ALARM_CLEAR
- Импульс отправляется на внешний драйвер для сброса его состояния неисправности
- Правильная последовательность с включением/выключением двигателя

---

### 7. Система асинхронных событий

**Система уведомлений о событиях:**
Хост получает асинхронные уведомления об изменениях состояния системы без опроса.

**Типы событий:**
- `EVENT BOOT` — система готова после включения питания
- `EVENT DONE <ось> <позиция>` — движение завершено
- `EVENT ERROR <ось|SYSTEM> <код>` — состояние ошибки
- `EVENT BRAKE <ось> ENGAGED/RELEASED` — изменение состояния тормоза
- `EVENT LIMIT <ось> MIN|MAX` — сработал концевой выключатель
- `EVENT ESTOP <статус>` — изменение состояния кнопки E-stop
- `EVENT INPOS <ось> <статус>` — статус серво "в позиции"
- `EVENT WIDTH <ось> <измерение>` — измерение ширины оси C завершено

**Тайминг событий:**
- Публикуются в течение 10 мс после возникновения условия
- Гарантирован хронологический порядок
- Отсутствие потери событий (управление буфером)

---

### 8. Интегрированное управление периферией I2C

**Расширители MCP23017 I2C:**
- **MCP23017 #0 (адрес 0x20):** 16 входов концевых выключателей (2 на ось)
- **MCP23017 #1 (адрес 0x21):** 7 сигналов ALARM_INPUT + 5 сигналов InPos + запасные входы
- Выделенная шина I2C0 на 400 кГц для быстрого отклика мониторинга
- Изолированная шина I2C1 для OLED-дисплея (не влияет на мониторинг концевиков)

**Мониторинг работоспособности I2C в реальном времени:**
- Проверка работоспособности связи I2C
- Автоматическое восстановление от кратковременных ошибок
- Сообщение об ошибке при недоступности шины I2C

## ПЛАНИРУЕМЫЕ ВОЗМОЖНОСТИ (после MVP)

### Эпик 5: Система конфигурации и статусный дисплей

**Система конфигурации YAML:**
- `CFGSTART` — начало загрузки конфигурации
- `CFGDATA <фрагмент>` — отправка данных конфигурации
- `CFGEND` — завершение конфигурации
- `CFGEXPORT` — экспорт текущей конфигурации в формате YAML
- Атомарные обновления конфигурации (полный откат при ошибке)

**Настройка параметров во время работы:**
- Изменение параметров движения без перекомпиляции
- Постоянное хранение через NVS (энергонезависимая память)

**Драйвер OLED-дисплея:**
- Дисплей 128x64 SSD1306 на выделенной шине I2C1
- Отображение позиций осей в реальном времени
- Индикация статуса E-stop (наивысший приоритет)
- Отображение ошибок/событий (таймаут 2 секунды)
- Мониторинг статуса и диагностика

**Псевдонимы осей:**
- `ALIAS X RAILWAY` — назначение пользовательских имен осям
- Удобные ссылки вместо одиночных букв

**Управление позицией:**
- `ZERO X` — обнулить позицию (без физического движения)
- `SETL X -10 10` — установить пределы хода
- `SETV X 50` — установить предел скорости

### Эпик 6: Расширенная обратная связь по позиции

**Синхронизация по Z-сигналу (индексный импульс энкодера):**
- Чтение Z-сигнала от индексных импульсов энкодера серво
- Обнаружение дрейфа позиции во время движения
- Автокоррекция при переходе оси в состояние простоя
- Настраиваемое резервное поведение (авто/подтверждение/отказ) при возврате в домашнюю позицию
- Возврат в дом по Z-сигналу для максимальной повторяемости

**Интеграция сигнала InPos:**
- Использование обратной связи InPos для подтверждения завершения движения
- Обнаружение ошибок позиционирования серво
- Обнаружение таймаута при проблемах с серво

**Обнаружение и коррекция дрейфа позиции:**
- Сравнение заявленной позиции с позицией по Z-сигналу
- Отложенные коррекции применяются в безопасный момент
- Сообщение о событиях дрейфа

## ХАРАКТЕРИСТИКИ СИСТЕМЫ

### Аппаратная платформа
- **МК:** ESP32-S3-DevKitC-1 (16 МБ Flash, 8 МБ PSRAM, двухъядерный 240 МГц)
- **Связь:** USB-C CDC serial
- **Периферия:** RMT, MCPWM, LEDC, PCNT, SPI2, I2C0, I2C1
- **Сдвиговые регистры:** 5x TPIC6B595N (цепь 40 бит) для выходов 24В
- **Расширители I2C:** 2x MCP23017 для 24 входов
- **Безопасность:** Аппаратный E-stop, отказобезопасные тормоза

### Целевые показатели производительности
- Генерация импульсов: до 500 кГц возможность
- Задержка команды: отклик <10 мс
- Опрос I2C: цикл <5 мс
- Детерминизм реального времени: максимальный джиттер 1 мс
- Надежность непрерывной работы 24+ часа

### Среда разработки
- ESP-IDF v5.4 LTS с FreeRTOS SMP
- Модульная компонентная архитектура
- Система сборки CMake
- Уровень аппаратной абстракции (HAL)
- Тестируемая конструкция с поддержкой имитации

### Возможности интеграции
- Совместимость с терминальными приложениями USB
- ROS2 hardware_interface (после MVP)
- Библиотеки хоста Python/C++ (планируется)
- Стандартный формат конфигурации YAML
- Система единиц СИ (метры, радианы, секунды)

## РЕЗЮМЕ

YaRobot Control Unit представляет собой комплексную, готовую к производству встраиваемую систему для управления различными типами двигателей через унифицированный, удобный интерфейс. Реализованные функции обеспечивают надежное управление движением, мониторинг безопасности и надежность для исследовательских и промышленных робототехнических применений.

**Основные области применения:**
- Станки с ЧПУ
- Робототехнические манипуляторы
- Автоматизированное испытательное оборудование
- Системы типа pick-and-place
- Любые многоосевые системы управления движением, требующие надежности и безопасности
